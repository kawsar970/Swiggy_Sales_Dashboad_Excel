# Excel Sales Data Analytics Dashboard

## Project Overview

This project presents an interactive Sales Data Analytics Dashboard developed using Microsoft Excel. The dashboard provides insights into sales performance, order trends, food categories, restaurant performance, and city-wise sales distribution.

The main objective is to analyze sales data and present meaningful business insights through interactive visualizations and KPIs.

## Dashboard Preview
![Excel Sales Dashboard](Images/sales_dashboard_preview.png)
## Key Performance Indicators (KPIs)
- Total Sales
- Total Orders
- Average Order Value
- Average Rating
- Rating Count

## Dashboard Features
- Daily Sales Analysis
- Monthly Sales Trends
- Sales by Food Type (Veg and Non-Veg)
- Top Restaurant Sales Analysis
- Top 5 Cities by Sales
- Quarterly Sales Performance
- Interactive Filters and Slicers
## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Slicers
- Data Analysis
- Data Visualization
## Interactive Filters
The dashboard includes the following filters:
- Month
- State
- Category
- Food Type
These filters help users explore sales performance across different business dimensions.
